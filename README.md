# PackDB OSS Organization Profile

This repository maintains the public [PackDB OSS organization profile](https://github.com/packdb-oss).

Edit [`profile/README.md`](profile/README.md) through a pull request. After merge
to `main`, GitHub displays it on the organization overview. Keep project links,
installation status, and compatibility language aligned with the public project
repositories. Do not include private roadmap details, credentials, or customer
information.
